Features that feel expensive

These are the bits that make a static site feel like a product.

✦

Scroll-reveal

Elements animate in as you scroll, with reduced-motion support built in.

  • IntersectionObserver
  • Staggered delays
  • Accessible defaults
⌘

Cmd-K Search

Hit Ctrl/⌘ K to search sections and jump instantly.

  • Keyboard-first
  • Fuzzy matching
  • Esc to close
◐

Dark Mode

System preference aware, stored locally, toggles instantly.

  • localStorage
  • Color-scheme hints
  • No flash
